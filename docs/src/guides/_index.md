These guides explain the conventions and workflows shared across the
API. Use the [API reference](../api-guide/) when you need a specific
signature or parameter.

- [Coordinates and Colors](coordinates-and-colors/) — pixel geometry,
  numeric overloads, angles, alpha, and anti-aliasing.
- [Shapes and Paths](shapes-and-paths/) — choose a primitive, construct
  paths, and control fills and strokes.
- [Transforms and State](transforms-and-state/) — user space, transform
  composition, clipping, and `save`/`restore`.
- [Text](text/) — font resolution, alignment, measurement, prepared
  layouts, and cache lifetime.
